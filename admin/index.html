Gestao do site

Painel administrativo com autenticacao e persistencia no servidor.

Gerencie noticias, eventos e avisos em um fluxo unico, com dados salvos no backend do projeto e mensagens do formulario de contato centralizadas no mesmo painel.

Servidor necessario

O backend do site ainda nao esta respondendo

Este painel depende do servidor Node do projeto para autenticar usuarios, salvar conteudos no backend e listar as mensagens recebidas pelo formulario de contato.

Inicie o projeto com npm start antes de usar a area administrativa.

Primeiro acesso

Criar acesso administrativo

Defina o primeiro usuario e senha do sistema. Depois disso, o acesso passa a ser validado pelo backend do projeto.

Em producao, configure ADMIN_SETUP_TOKEN na hospedagem antes de liberar o primeiro acesso administrativo.

Acesso restrito

Entrar no painel

Entre com as credenciais administrativas salvas no servidor para editar o conteudo publicado pelo site.

Servidor conectado. As alteracoes ficam persistidas no backend do site.

Painel ativo

Conteudo administrado por admin

As alteracoes salvas aqui atualizam o acervo dinamico do site, com autenticacao persistida no servidor e sem depender do navegador local.

Baixar backup JSON

As atualizacoes ficam salvas ao fechar o site?

Sim. Os dados agora ficam persistidos no backend do projeto, entao continuam disponiveis mesmo ao trocar de navegador ou encerrar a sessao.

Backend do projeto

O painel agora grava conteudo, credenciais e mensagens de contato no servidor do site, criando uma base real de administracao para a equipe.
