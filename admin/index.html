Gestao do site

Painel administrativo com autenticação e persistência no servidor.

Gerencie notícias, eventos e avisos em um fluxo único, com dados salvos no backend do projeto e mensagens do formulário de contato centralizadas no mesmo painel.

Servidor necessário

O backend do site ainda não está respondendo

Este painel depende do servidor Node do projeto para autenticar usuários, salvar conteúdos no backend e listar as mensagens recebidas pelo formulário de contato.

Inicie o projeto com npm start antes de usar a área administrativa.

Primeiro acesso

Criar acesso administrativo

Defina o primeiro usuário e senha do sistema. Depois disso, o acesso passa a ser validado pelo backend do projeto.

Em produção, configure ADMIN_SETUP_TOKEN na hospedagem antes de liberar o primeiro acesso administrativo.

Acesso restrito

Entrar no painel

Entre com as credenciais administrativas salvas no servidor para editar o conteúdo publicado pelo site.

Servidor conectado. As alterações ficam persistidas no backend do site.

Painel ativo

Conteúdo administrado por admin

As alterações salvas aqui atualizam o acervo dinâmico do site, com autenticação persistida no servidor e sem depender do navegador local.

Baixar backup JSON

As atualizações ficam salvas ao fechar o site?

Sim. Os dados agora ficam persistidos no backend do projeto, então continuam disponíveis mesmo ao trocar de navegador ou encerrar a sessão.

Backend do projeto

O painel agora grava conteúdo, credenciais e mensagens de contato no servidor do site, criando uma base real de administração para a equipe.
